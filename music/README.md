# Intentionally Yours music library

Original tracks composed for this account (no licensing needed). Each runs about 33–37 seconds: a one-bar build, then the beat drops. Loudness is normalized to -14 LUFS.

| # | Track | BPM | Key / progression | Best for |
|---|---|---|---|---|
| 01 | Rise | 124 | B minor: Bm–G–D–A | Launches, the planner (batch 1 uses this one) |
| 02 | Momentum | 128 | A: A–E–F#m–D | Product promos, countdowns |
| 03 | Clear Path | 118 | C: C–G–Am–F, piano-led | Tips, how-it-works |
| 04 | Daily Number | 122 | E minor: Em–C–G–D | Stats, the math |
| 05 | Golden Hour | 112 | F: F–Am–Bb–C, softer | Brand and mindful content, quotes |
| 06 | Breakthrough | 126 | G: G–D–Em–C, syncopated | High-energy reveals |
| 07 | Forward | 120 | D: D–A–Bm–G | Weekly planning, Sunday reset |
| 08 | Big Year | 125 | E-flat: Cm–Ab–Eb–Bb | New year and goal-setting pushes |

Rotation: go through 02 to 08 in order, then repeat. Don't use the same track twice in a row. Match the mood using the "Best for" column.

To regenerate or extend a track: run `python3 tracks.py`, which needs `lib.py`.
